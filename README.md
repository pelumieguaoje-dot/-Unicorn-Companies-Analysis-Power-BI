# -Unicorn-Companies-Analysis-Power-BI
🦄 Unicorn Companies Analysis Dashboard | Power BI Analysis

## Project Overview

This project presents an interactive Power BI dashboard analysing unicorn companies across different industries and geographical locations.

The dashboard explores company valuations, funding raised, industry performance, geographical distribution, and the yearly trend of companies achieving unicorn status.

The aim is to transform company data into meaningful visual insights that support business understanding and data-driven decision-making.

## Project Objectives

- Analyse the number of unicorn companies.
- Examine company valuations and total market capitalisation.
- Explore how long companies take to achieve unicorn status.
- Identify the leading industries by valuation.
- Compare funding raised with current company valuations.
- Examine the geographical distribution of unicorn companies.
- Understand yearly trends in unicorn company growth.

## Tools Used

- Microsoft Power BI
- Power Query
- Data Visualisation
- Data Analysis

## Dashboard Features

### 1. Key Performance Indicators (KPIs)
The dashboard includes four major indicators:
- Unicorn Count
- Total Market Cap
- Average Years to Unicorn
- Average Valuation

### 2. Unicorn Growth Trend
A column chart displays the number of unicorn companies by year joined, helping users explore how unicorn company growth changes over time.

### 3. Industry Analysis
A bar chart highlights the top four industries based on company valuation.

### 4. Interactive Filters
Users can filter the dashboard by:
- Industry
- Continent

### 5. Funding vs Valuation
A scatter chart compares funding raised against current company valuation to explore the relationship between investment and company value.

### 6. Geographical Analysis
A map visualises unicorn company valuations by country, providing a geographical perspective on the global unicorn ecosystem.

## Report Analysis

The dashboard is designed to explore several important business questions:

**Company Growth:** How has the number of unicorn companies changed over the years?

**Industry Performance:** Which industries account for the highest company valuations?

**Funding and Valuation:** How does funding raised compare with the current valuations of companies?

**Geographical Distribution:** Which countries contribute to the global unicorn ecosystem?

**Time to Unicorn Status:** How many years do companies take, on average, to reach unicorn status?

The dashboard provides an interactive way to investigate these questions using KPI cards, charts, maps and filters.

## Business Value

This analysis can help business professionals, investors and researchers understand the global unicorn ecosystem, explore industry trends, compare company funding and valuations, and identify geographical patterns.

## Conclusion

This Power BI project demonstrates the use of business intelligence and data visualisation to explore global unicorn companies.

By combining key performance indicators, industry comparisons, funding analysis and geographical visuals, the dashboard provides an interactive foundation for understanding the growth and distribution of high-value private companies.
